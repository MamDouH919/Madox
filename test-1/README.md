# 🍗 هنطبخ إيه النهارده؟

استبيان كوميدي تفاعلي بيتبعت للمدام بدل ما ترد على سؤال «هتطبخ إيه النهارده؟».
مبني بـ Next.js + TypeScript + Tailwind CSS. مفيش Backend ولا قاعدة بيانات.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح http://localhost:3000

عشان تجربه من الموبايل على نفس الواي فاي: `npm run dev -- -H 0.0.0.0`، وبعدين افتح `http://<IP-الكمبيوتر>:3000` من الموبايل.

## الأوامر

| الأمر | بيعمل إيه |
| --- | --- |
| `npm run dev` | تشغيل للتطوير |
| `npm run validate` | يمشي على كل المسارات ويتأكد إن كلها بتوصل لنهاية (`-- --verbose` لعرض كل مسار) |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run lint` | فحص الكود |

## تعديل الأسئلة والنهايات

كل المحتوى في ملف واحد: **`src/data/scenario.ts`**

- **سؤال جديد:** ضيف object في `questions` بـ `id` جديد، وخلّي إجابة في سؤال تاني تشاور عليه بـ `next`.
- **آخر سؤال:** إجاباته بيكون `next: END`.
- **تاجز:** كل إجابة ممكن تسجل `tags`، والنهايات بتتختار على حسبها.
- **نهاية مشروطة:** `when: { all: [...], any: [...], none: [...] }` + `priority` (الأعلى بيكسب).
- **نهاية عشوائية:** نهاية من غير `when`، وبتطلع لأي حد. `weight` بيكبّر فرصتها.
- **`randomEndingChance`:** نسبة إن تطلع نهاية عشوائية حتى لو في نهاية مشروطة مناسبة (حاليًا 25%).
- **رد فعل سريع:** `reaction: "..."` على أي إجابة بيظهر فقاعة كوميدية ثانية بعد الاختيار.
- **أسئلة خادعة:**
  - `trick: { type: "runaway", dodges: 4, surrenderText: "..." }`: الزرار يهرب كذا مرة وبعدين يستسلم.
  - `trick: { type: "swap", newLabel: "..." }`: الزرار يغيّر كلامه أول ما تدوسي عليه.
- **المؤثرات:** `effect`: `confetti` / `emoji-rain` / `shake`، و`sound`: `fanfare` / `sad-trombone` / `ding` / `drumroll-hit`.

بعد أي تعديل شغّل `npm run validate`. هيطلع خطأ لو في سؤال بيشاور على حاجة مش موجودة، أو في حلقة لا نهائية، أو مسار مالوش نهاية، وهيحذّرك من أسئلة محدش بيوصلها أو نهايات مستحيل تطلع.

## النشر على Vercel

### الطريقة الأولى: من GitHub (الأسهل)
1. ارفع المشروع على GitHub:
   ```bash
   git add -A && git commit -m "first version"
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```
2. ادخل على https://vercel.com/new واختار الـ repo.
3. سيب كل الإعدادات زي ما هي (Vercel بيتعرف على Next.js لوحده) ودوس **Deploy**.
4. هتاخد لينك ثابت زي `https://<project-name>.vercel.app`. ده اللي تبعته على واتساب.
   أي `git push` بعد كده بيحدّث الموقع على نفس اللينك.

### الطريقة التانية: من الترمينال
```bash
npx vercel          # أول مرة: هيسألك تسجل دخول ويربط المشروع
npx vercel --prod   # نشر نسخة الإنتاج
```

💡 لو عاوز لينك مش باين إنه مقلب: من **Project Settings → Domains** غيّر اسم المشروع لحاجة رسمية زي `food-survey-2026.vercel.app`.
